# OnePoint 🎯

Your All-in-One Utility Suite built specifically to empower individuals and NGOs with free, high-performance tools.

## 🚀 Features

OnePoint provides a clean, premium, and glassmorphism-styled interface to access powerful utilities running locally and securely on your own server.

- **PDF Tools**: 
  - Convert multiple Images to a single PDF document.
  - Compress large PDFs (MB to KB) dynamically.
- **Image Tools**: 
  - Resize images to exact pixel dimensions.
  - Remove backgrounds seamlessly using a local built-in engine.
- **Smart Assistant**: 
  - A custom conversational interface designed to provide immediate answers and guidance about the software.

## 🛠 Tech Stack

**MERN Stack Architecture**
- **Frontend**: React.js, Vite, Vanilla CSS
- **Backend**: Node.js, Express.js
- **Processing Libraries**: `pdf-lib` (PDF manipulation), `sharp` (Image processing), `@imgly/background-removal-node` (Background removal)

## 💻 Running Locally

To get started with OnePoint locally, you'll need Node.js installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ArpitDubey009/OnePoint.git
   cd OnePoint
   ```

2. **Install Backend Dependencies and Start Server:**
   ```bash
   cd server
   npm install
   node server.js
   ```
   *The backend will run on `http://localhost:5000`.*

3. **Install Frontend Dependencies and Start Client:**
   Open a new terminal window:
   ```bash
   cd client
   npm install
   npm run dev
   ```
   *The frontend will run on `http://localhost:5173`.*
